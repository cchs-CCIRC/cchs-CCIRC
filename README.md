## 💡 我們是誰

**CCIRC** is short for ***C**hing **C**heng high school **I**nformation **R**eading **C**lub*

**精誠高中資訊讀書會 CCIRC**是一個以 C++ 競技程式設計為核心的學生讀書會。

我們透過課程、實作與交流，帶領對程式設計有興趣的同學學習演算法與資料結構，並一起挑戰 APCS、TOI 等資訊競賽。

---

## 💻 我們在做什麼

- `C++ 程式設計`
- `演算法與資料結構`
