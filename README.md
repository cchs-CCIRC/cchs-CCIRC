精誠高中資訊讀書會（CCIRC）是一個以 **C++ 競技程式設計**為核心的學生讀書會。

我們希望讓對程式設計有興趣的同學，從基礎開始接觸演算法、資料結構與競技程式設計，並一起挑戰 **APCS、TOI** 等資訊競賽。

---

## 💻 What We Do

- C++ 程式設計
- 演算法與資料結構
- 競技程式設計
- APCS 準備
- TOI 準備
- 程式設計教學與交流
- 學習資源整理
